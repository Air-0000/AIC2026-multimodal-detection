## 两个“P3/P4”必须分开

- **查询配额（A01）**：decoder从P3/P4/P5候选中如何选Query，改变候选集合。
- **融合注入位置（A02）**：backbone在哪个stage注入IR，改变特征流。

A02平均AP75提升约1.40pp、mAP下降约0.15pp，只属于注入位置的这次实验；不能用来证明A01的路由、DOG或Aux有效。四条均从冻结的V36 epoch32 EMA热启动，也不是从50轮最终最佳权重重新开始。

A02的预设判据是 **small-tight +3pp且no_candidate不升**，不能用AP_small代替small-tight。RNG未按原计划在加载后重置，普通BN更新；两个seed、八轮热启动也不足以宣称显著性或纯拓扑因果收益。
