## 一、 项目全景与工程基础设施

- **任务目标**：复杂城市场景（涵盖昼夜光照剧烈变化、逆光泛光、水面倒影、浓雾微光）下的 12 类高精度视觉目标检测。
- **12 个目标类别**：`person`, `boat`, `animal`, `seat`, `sign`, `bicycle`, `car`, `ball`, `light`, `garbage can`, `uav`, `tricycle`。
- **输入模态**：RGB 彩色图、对齐红外热成像（Aligned IR）、局部背景抑制红外（LBG IR）、绝对公制深度图（P0 Depth）。
- **评价标准**：严格遵循 COCO mAP (IoU 0.50:0.95)，兼顾小、中、大目标检测能力。

### 1.2 计算与存储环境演化

  - GPU：NVIDIA RTX PRO 6000 Blackwell (96GB 显存，单卡满血旗舰)
  - CPU：208 核高性能多线程计算节点
  - 显存/内存加速：`/dev/shm/aic_cache` 全模态 RAM 内存盘高速缓存（全量载入 `visible`, `train_aligned_ir`, `train_lbg_ir`, `depth_p0`），训练 I/O 耗时彻底归零。在 Sovereign V12 阶段启用 `total_batch_size: 24`，8 轮完整训练仅用时 15 分 55 秒，显存利用率稳定在 70.2GB / 96GB。

## 二、 全周期人机交互与技术演进编年史

### 2.1 阶段零：多模态数据治理、三阶对齐与物理先验重构
- **用户痛点与核心发现**：
  - 原始数据集红外图像与 RGB 图像存在明显的相机视差（Parallax）与非刚性装配位移；
  - 深度图原始为伪彩色 8 位图像，丢失了真实世界的绝对公制距离信息。
- **技术突破**：
  1. **三阶红外几何对齐流水线（IR Registration）**：通过特征匹配与单应性变换（Homography），在像素级消除 RGB 与 IR 的边缘剪切差。
  2. **物理自参考局部背景抑制（LBG）**：消除红外图像在高温背景（路面、墙体发热）下的“热晕漂移”，保留孤立高热目标。
  3. **P0 绝对公制深度图重构**：将伪彩色映射恢复为单通道 16 位毫米级距离场 $Z \in [0.3m, 20m]$，为几何感知奠定绝对物理地基。

### 2.2 阶段一：异构主干蒸馏与 Sovereign 系列起源
- **设计初衷**：Transformer 大模型（DINOv3-L, 56.71% mAP）表征能力极强，但推理延迟高、显存占用大；卷积大模型（HGNetv2-X）推理极快但深层长程依赖欠缺。
- **关键行动**：
  - 确立以 HGNetv2-X 作为主干的学生网络，构建 Sovereign 蒸馏管线；
  - 引入特征级蒸馏（DNDT / Feature Mimicry）与逻辑回归蒸馏，学生网络一举突破 56% 门槛，奠定 Sovereign 骨架底座。

### 2.3 阶段二：多模态物理先验注入（Sovereign V2 / V3）
- **架构创新四大件**：
  1. **DCDA (Depth-Conditioned Deformable Alignment)**：深度条件可形变注意力，以 $1/Z$ 视差先验约束红外采样的形变场偏移，防止在无深度区域乱扯拉花。
  2. **DOG (Depth Occlusion Gating)**：深度不连续截断门控，通过 Sobel 梯度算子提取深度阶跃边界，利用门控网络阻断红外热量向背景扩散。
  3. **3D-Lift (三维公制空间坐标抬升)**：利用相机针孔模型将 2D 特征网格与深度 $Z$ 反投影为物理空间三维坐标 $(X, Y, Z)$，为网络赋予公制空间感知。
  4. **Bilateral Pooling (双边反混叠下采样)**：以深度相似性为核的高频滤波下采样，消灭跨深度边缘的特征混叠。
- **战果**：Sovereign V2/V3 在复杂物理场景下全面稳定，验证集达到 56.40% mAP。

### 2.4 阶段三：频域残差傅里叶引导模块（RFGM / RF-ProG）攻坚
- **用户指令与攻坚背景**：针对频域处理的 5 大传统缺陷深入改造（阶段间流失、通道孤立、不可靠误差、计算冗余、相位补偿不足）。
- **架构落地**：
  - 设计 **RF-ProG (Residual Fourier-Guided Module)**：
    - 利用 2D 实数快速傅里叶变换（2D-rFFT）解耦幅度（全局照度/能量）与相位（结构轮廓/边缘几何）；
    - 浅层 Stage 0（$160\times160$ 尺度）相位残差直通至 Neck P3，绕过深层卷积衰减；
  - **战果**：Sovereign V4 验证集跃升至 **56.67% mAP**，小目标交通标牌（`sign`）单类 AP 从 41.29% 爆发式拉升至 **43.11%（+1.82%）**，AP75 达到 61.60%。

### 2.5 阶段四：物理后处理规则的辩证推演与红线标定
- **用户针对两项关键后处理的深入探讨与验证**：
  1. **水际线纵横比截断（Waterline Rectification, $H > 1.25W$）**：针对长宽比异样高耸的船只执行吃水线底边收紧，彻底阻断水面镜面反射与散斑破坏 IoU。
  2. **同类孪生框高 IoU 软融合（Soft-WBF, $\text{IoU} \ge 0.82$）**：严格仅允许在 `car`, `seat`, `boat` 上生效；**严禁在 `person` 和 `animal` 上使用**，防止成群结队的动物或密集人群被错误合并成一个大框。
  3. **3D 公制物理尺寸硬过滤的废止**：实测发现真实世界存在目标屈体以及相机焦距的非严格标定，硬性物理过滤导致 mAP 骤降 1.2%，坚决剔除。

### 2.6 阶段五：纯净单图边界精炼（MAL2 + GIoU 3.5x）登顶历史极值
- **用户核心发问**：“之前说的 mal2，giou 怎么没上，下采样不也优化过了吗？还有什么不够好？”
- **技术对策**：彻底关闭 Mosaic 与随机裁剪，恢复 $640\times640$ 真实物理原图；边界损失 `loss_giou` 与匈牙利匹配拔高至 **3.5x**；引入模型感知边界自适应损失（MAL2）。
- **战果**：Sovereign V5 诞生，验证集达到 56.77% mAP（0.56769），无人机（`uav`）达成 58.05% AP（AP50 达到 100% 满分）。

### 2.7 阶段六：Phase 2 官方 1,000 张测试集深度图与权威提交包制备
- **测试集预处理**：在远端 208 核 CPU 上以 8 进程并行调度 `prep_p0_depth_unified.py`，全量完成 1,000 张 Phase 2 测试集的 16 位毫米级公制深度图生成。
- **打包生成**：运用 Sovereign V5 执行 6 通道多模态推断，叠加物理水际线修正与孪生框软融合规则，生成 `submission_sovereign_v5.zip`。

### 2.8 阶段七：深层结构瓶颈诊断与 Mamba / 2D-SSM 下一代架构攻坚
- **用户关键问题**：“这样除了最终杠杆走到头了吗，模型结构还能改吗，残差连接啊，mamba 等等各种优化有什么缺陷做什么优化？继续打磨结构。”
- **结构缺陷科学诊断**：$AP_{large} = 72.91\%$，而 $AP_{small} = 29.04\%$，两者落差达 **43.87%**！核心病根在于 DETR 解码器舍弃了 P2（stride 4, $160\times160$），而 P3/P4 缺乏全局长程感知。
- **Mamba-CCFM 混血颈设计**：利用双向 2D-SSM 的 $O(N)$ 线性空间复杂度赋能 P3/P4 全局视界，设计 100% 零初始化（Zero-Init）机制，确保无损继承前代成熟权重。

### 2.9 阶段八：Sovereign V6（Mamba-CCFM 2D-SSM 线性全局长程关联落地）
- **核心实现**：在 `HybridEncoder` 的 Level 0 (P3) 与 Level 1 (P4) 部署 `BiDirectionalSSM2d` 算子，四向扫描全局上下文。
- **实测战果**：验证集 mAP 跨越式升至 **57.14%**（AP75 达到 60.92%），小目标 AP 提升至 32.26%，全局长程依赖瓶颈得到显著突破。

### 2.10 阶段九：Sovereign V9（暗区信噪比感知边界分布锐化头与 MSRB 主干直通桥）
- **核心手术**：
  1. **暗区信噪比感知边界分布锐化头 (SNR-Aware FDR Head)**：在 Integral 积分层引入 Query 语义感知的自适应温度缩放头（`temp_head`），暗光弱对比度下动态降温（$\tau < 1.0$），强制尖锐化弥散的 33 维 Softmax 边界分布，彻底消灭暗区中心漂移。
  2. **MSRB 主干微残差直通桥**：Stage 0 ($160\times160$) 128 通道深层特征通过 `s0_to_p3_trunk` 直通注入 P3 ($80\times80$)。
  3. **保峰双路池化 (Peak Salience Dual Pooling)**：平均池化 + 最大池化并联，保护超小高频特征。
- **实测战果**：标准评测达到 **57.33% / 57.41% mAP**，三轮车达成 75.15%（100% AP50），无人机达到 59.75%（98.2% AP50），汽车突破 61.31%。

### 2.11 阶段十：AIC 真实物理分辨率突破（16:9 真实画幅解剖与防拉伸畸变推演）
- **用户敏锐提问与发现**：“不是要提高训练分辨率，只是提高图像的分辨率。AIC 数据集在磁盘上的真实尺寸其实是 16:9，并不是正方形！当前直接 Resize [640, 640] 垂直强行拉伸了 1.78x！”
- **真实几何事实排查**：
  - 全量排查 200 张验证集：**184 张为 $1920\times1080$**，**16 张为 $640\times360$**。
  - 两者均严格符合 $16:9$（比例 1.777778），全数据集在历史训练中均遭受了 1.78x 垂直非均匀挤压。
- **原生 16:9 画布推演**：设计 Canvas $1138\times640$，以物理等比例放大映射切片（Left [0:640] 与 Right [498:1138]），辅以全局上下文 P0 [640x640]，消除纵向几何畸变。

### 2.12 阶段十一：输入前端双模态物理共增强（USM + Depth-Guided Thermal Boost）
- **用户指令与评测需求**：“输入前端红外 CLAHE 与深度先验引导红外梯度共增强，可以测试，还有怎么确认 USM 是有效增益的。”
- **实测对比与机制判明**：
  1. **输入前端 USM 反锐化掩模**：单独开启 USM（未加 SAHI），验证集 mAP 从 55.90% 提升至 55.95%，`boat` AP 暴涨 +1.52%，`bicycle` +0.60%，确凿证实高频增强对边缘模糊物体的有效物理增益。
  2. **红外 CLAHE（局域直方图均衡）的失效分析**：实测 mAP 跌落至 57.07%，`boat` 从 43.19% 跌至 42.03%。根因：纯 2D 统计的 CLAHE 不感知 3D 几何，无差别放大了水面波纹与暗区红外传感器底噪。
  3. **深度先验引导的红外热梯度共增强（Depth-Guided Thermal Boost, DGTB）**：以深度不连续阶跃作为物理安全门，平坦水面与地面噪点完全被置零阻断，仅锐化真实实体边缘，mAP 冲上 **57.34%**！

### 2.13 阶段十二：拖后腿三类专项攻坚与 CAA-SAHI 类别自适应门控（57.48%~57.73% 峰值）
- **架构解法：类别自适应门控超推理（CAA-SAHI）**：
  - **大跨度与宽高比敏感类别（`boat`, `ball`）**：锁定全局 P0 上下文统一视图，彻底消除切片缝隙切割与纵向偏心畸变，叠加 USM 物理锐化。
  - **密集与微弱小目标类别（`sign`, `garbage can`, `uav`, `car`, `person`, `light`）**：路由至原生 16:9 高清无损切片流。
- **战果**：Sovereign V9 叠加外部 CAA-SAHI 脚本外挂达到 **57.73% mAP**（AP50 达到 86.92%）。但此方案强依赖外部独立 Python 脚本，存在坐标微移与部署脆弱性。

### 2.14 阶段十三：Sovereign V10/V11（P2-CSRG+ 小波条带手术、天水去噪与 SAHI 切片内化 58.10%）
- **用户核心定位与发问**：
  - “还有之前的后处理之后不是有 57.7 吗那时候处理前有 57.4 现在怎么又从 57.1 开始比了？水面和天空也注入了高频噪声去除还有 CAA-SAHI 切片内化。”

## 四、 核心物理机制与算法实现深度总结

### 4.1 V1-218 MHLA 多头线性注意力（ICLR 2026）
利用正向核映射 $\phi(x) = \text{ELU}(x) + 1.0$，将传统自注意力关联式重排：
$$\text{Attention}(Q, K, V) = \frac{\phi(Q) \left(\phi(K)^T V\right)}{\phi(Q) \left(\sum \phi(K)^T\right)}$$
先计算维度仅为 $d_k \times d_v = 64 \times 64$ 的特征矩阵，计算复杂度从 $O(N^2)$ 严格骤降为 $O(N)$。与 Mamba 2D-SSM 算子并联构成双核超长程特征颈，全无偏覆盖全图跨模态上下文。

### 4.2 V1-153 DIAM 可变形交互注意力（一区TOP 2025）
针对可变形注意力在极端细长目标（如高耸立柱，长宽比 $w/h \approx 0.20 \sim 0.35$）上采样点容易分散到背景噪波的问题，DIAM 引入了几何-语义交互网络：
$$\Delta_{\text{offsets}} = \text{MLP}\left([Q, cx, cy, w, h]\right)$$
当几何长宽比 $w \ll h$ 时，横向偏移被自适应压缩，采样点强制紧锁于立柱中轴骨架；当 $w \gg h$ 时，采样点贴紧刚体龙骨线。

### 4.3 V1-054 傅里叶对比正则化损失（ECCV 2024）
对 FDR 边界概率分布预测张量沿离散 Bin 维度执行 1D 实数离散傅里叶变换（cuFFT）：
$$F(k) = |\text{RFFT}(P_{\text{corners}})|$$
利用正样本（真实物体尖锐边缘，高频能量充沛）与负样本（背景杂波，能量聚集在低频）的频谱能量分布差异，通过余弦 Hinge 损失强行拉大表征间距：
$$\mathcal{L}_{fcr} = \frac{1}{|P|} \sum_{i \in P} \text{ReLU}\left(\cos(\bar{F}_{pos, i}, \bar{F}_{neg\_proto}) - 0.3\right)$$
推理阶段零参数零耗时。

### 4.4 天水深度梯度高频去噪器 (`Sky-Water Noise Attenuator`)
利用度量深度图梯度 $|\nabla Z| = \sqrt{G_x^2 + G_y^2}$，构造空间衰减遮罩 $M_{clean}$：
$$M_{clean} = 1.0 - \mathbb{I}(Y < 0.28 \land Z < 0.02) - \mathbb{I}(Y > 0.48 \land |\nabla Z| < 0.015)$$
天空与平坦水面的高频增益被强制截断归零，彻底根除水面波纹反光与日光晕影对 P2 高频直通桥的污染。

### 4.5 内生化 CAA-SAHI 3-View 高清切片前传
在 `DEIM.forward()` 内部完成全流程端到端闭环：
```
输入图像 (B, C, H, W) ──> [动态扩展至 640x1152 画布]

                    ┌──────────────┼──────────────┐

               全局视场 P0    左侧切片 P1    右侧切片 P2
                (640x640)      (640x640)      (640x640)
                    └──────────────┬──────────────┘
```

### 9.3 核心失效模式物理根因深度剖析与模型级原生突破
针对用户指出的五大失效缺陷，团队深入底层算子与损失函数进行地毯式排查，成功定位了三大物理根因并实施了针对性的模型级修复：

#### 根因一：`ConvertBoxes` 算子遗漏引发边界坐标爆炸与边缘畸变假框的彻底根除
- **故障病理解剖**：
  - 经深入排查数据预处理流水线发现，在某次增广重构中，`transforms.ops` 末端偶然遗漏了 `- {type: ConvertBoxes, fmt: 'cxcywh', normalize: True}` 算子；
  - 导致输入给 Hungarian Matcher 的 Ground Truth 为绝对像素坐标 $[0, 2048]$，而预测头输出为归一化相对坐标 $[0, 1]$；
  - 尺度不匹配导致边界框定位损失 `loss_bbox` 瞬间爆炸至 **16,032**，回归头严重震荡失控，在画幅右边缘（$x \to 2048$）盲目外推大量贴边极大值畸变伪框。
- **模型级原生修复**：
  - 在 Sovereign V26 中强制补齐所有训练与验证流水线的 `ConvertBoxes (fmt: 'cxcywh', normalize: True)` 算子；
  - 训练日志实证：`loss_bbox` 瞬间平复回归至极度健康的 **0.28 ~ 0.32** 区间，模型输出端的画布边缘畸变假框直接彻底归零。

#### 根因二：从“对称IoU”到“整体-局部包含度约束”（Part-Whole Appendage NDSL Containment）——根除孔雀身尾割裂
- **故障病理解剖**：
  - 传统 NMS 与初版 NDSL 均依赖对称交并比 $\text{IoU} = \frac{|A \cap B|}{|A \cup B|}$；
  - 对于孔雀等具有细长尾羽的特殊生物，尾羽面积远大于身体且两框重叠交集相对总体并集较小，导致对称 $\text{IoU}$ 轻易跌破 0.25 门限，网络匹配器因而分配了两个独立的 Query 正样本，将“身体”与“尾巴”割裂预测为两只 `animal`。
- **模型级原生修复**：
  - 在 [`vendor/DEIMv2/engine/deim/deim_criterion.py`](../../vendor/DEIMv2/engine/deim/deim_criterion.py) 的 `DEIMCriterion` 中升级近邻冗余损失（NDSL），引入 **空间包含度比率（Containment Ratio）**：
    $$\text{Containment}(B_1, B_2) = \frac{\text{Area}(B_1 \cap B_2)}{\min(\text{Area}(B_1), \text{Area}(B_2))}$$
  - **动态挂件惩罚机制**：当两个同类候选 Query 满足 $\text{Containment} \ge 0.40$ 或 $\text{IoU} \ge 0.25$ 时，判定较小框为从属局部挂件/肢体分裂，对其分类 Logits 施加高达 **$3.5\times$ 负向梯度惩罚**；
  - 驱动网络在特征层抑制局部肢体 Query 的置信度，强行迫使单一主 Query 扩张包围盒，将身体与长尾统一回归为一个完整的整体大框。

#### 根因三：环境弱目标解抑机制（Ambient Facility Softening）——精准找回凉亭长椅与走廊灯泡
- **故障病理解剖**：
  - 此前为压低暗光环境中的大面积背景虚警，模型对设施类别施加了过强的负样本惩罚因子；
  - 导致对比度较低的亭内连体长椅（`seat`）以及尺度微小的走廊连续吸顶灯泡（`light`）在 TADL（任务对齐动态学习）损失中受到过度压制，分类得分被系统性削低。
- **模型级原生修复**：
  - 在 `sovereign_v26_model_repair.yml` 中实施精准软化：将 `cls_neg_scale` 中的 `seat` 负惩罚系数自 1.0 降至 0.6，`light` 降至 0.6，`sign` 降至 0.7；
  - 将 `tadl_min_iou` 门限由 0.35 降低至 0.15，彻底释放弱小低对比度环境设施的正向学习梯度，确保真实凉亭木椅与连续走廊灯泡的高灵敏度原生召回。

### 9.8 认知破坏深刻反思与三大不可动摇工程原则 (2026-10-05 用户定案与不可逾越红线)

团队经全量特征空间反思，正式确立三大不可动摇的研发原则与不可逾越红线：
1. **统一权重，纯粹端到端（回归 1.0 原生平衡）**：
   - 所有类别的负样本惩罚因子 $w_{neg}$ 严格恢复为 **1.0**。坚决废除任何 `cls_neg_scale: [..., 0.6, ...]` 等人工打补丁倾斜。

2. **动态 Focal 调制（Dynamic Modulation）**：
   - 难易样本必须由模型自身的预测概率 $(1 - p_t)^\gamma$ 动态调节——对于已经确信是背景的区域自动降权，对于混淆边缘自动增权，绝不允许人工指定“一刀切”的标量常数。

   - 草坪地面的石块、路缘石之所以不是椅子，是因为其 3D 深度点云与地面法向量完全平行。必须通过 3D-PPR 局部平面残差从物理几何层彻底滤除地表，远比在 Loss 里盲目改个 0.6 科学严密得多。
4. **警惕表征漂移与认知破坏**：
   - 连续短周期带偏微调会导致解码器语义原型崩溃（如把黑衣行人认不出、草坪石条认成椅子、地表白斑认成球）。保持骨干与解码器物理常识认知纯净度是最高优先红线。

### 1. 2.5K (1440×2560) 原生超高清与 Meta DINOv3 在线微创蒸馏
- **升维背景**：672 底模与 2048 分辨率下的几何红利已充分吸收，为突破微小无人机与极端远景小目标的几何感知瓶颈，全面升维至 2.5K (1440×2560) 原生画幅。
- **V29 在线微创蒸馏**：首创在 2.5K 画幅下将 Meta 官方 300M 参数的 DINOv3-ViT-Large 语义特征微创蒸馏至 CNN 骨干（`distill_cos_weight: 1.0`, `distill_gram_weight: 0.5`，2x 下采样设计仅耗 2.0GB 显存）。V29 Cycle 5 斩获 7,178 框，mAP 达 0.5808。
- **V30 CSSP 谱空感知**：引入谱空互补通道与自适应加权门控 (ABC)，8 轮快速微调 AP50 冲至 0.8744。

### 2. 辅助监督与物理图引导
- **V31 Co-ATSS 一对多辅助密集监督**：彻底解决 DETR 类模型一对一匈牙利匹配在前期正样本梯度稀疏、收敛缓慢的死穴；训练阶段提供丰富正向梯度，推理阶段自动切除辅助头，零推理开销。
- **V32 PIG 物理归纳偏置**：引入地面几何拓扑与相机俯仰角先验约束，净降 130 处空旷背景虚警。
- **V33 跨模态差分失败清退**：CmDRM 差分残差调制破坏主干语义稳定性，引发小样本灾难性遗忘 (mAP 暴跌至 0.267)，团队果断物理清退并归档负例经验。

## 阶段十：Sovereign V34 ~ V37 纯血从零冷启动生产与 P2-CSRG 浅层高频手术 (2026-10-15 ~ 2026-10-21)

### 1. Clean-Slate 从零冷启动生产规范确立
- **彻底脱离旧权重**：为彻底杜绝历史微调权重、多段式预训练及质量补标带来的潜在数据污染与官方口径偏倚，确立从开源 COCO 底模 50 轮全量从零冷启动生产规范。
- **Sovereign V34 (纯血一代)**：2.5K 原生 + DINOv3 语义蒸馏 + Co-ATSS 辅助头，达成从零冷启动生产基线（mAP 52.03% / AP50 82.03% / 7,175 框）。

### 2. 空间排斥独占查询与 P2 浅层高频特征释放
- **Sovereign V35 (独占查询二代)**：针对 Co-ATSS 在目标中心区域激发多重正样本导致 180 对同实体多框重叠的问题，发明 **SDQS（空间排斥独占查询选择）**，在 Decoder 入口执行 $3 \times 3$ 空间局部极大值滤波，强行压制中心峰值周围紧邻单元，使测试集重叠框清零至 0 对。
- **Sovereign V36 (P2-v10 直通三代)**：
  - 释放主干网 Stage 0（Stride 4, $360 \times 640$ 高精细粒度特征图）；
  - 引入 **P2-CSRG 跨尺度双路保峰池化 (Avg+Max)**，严格零初始化无损直通 HybridEncoder P3；
  - 解决 micro-batch 激活图驻留引发的显存泄漏，纯 FP32 下单步压缩至 0.95s；
  - 50 轮纯 FP32 冷启动完赛：mAP 53.98%，AP50 达到 83.69%，UAV（微小无人机）AP50 跃升至 95.49%，产出 7,260 框官方 Phase 2 提交包。
- **Sovereign V37**：针对测试集双目极线微小装配偏差，完成 +1px 亚像素平移诊断（AP 52.02%），为纯净基准提供双目对齐实证边界。

## 阶段十一：纯净基准 v1（Clean Baseline v1）14 项通用缺陷修复与 55.94% 纯血历史最高纪录 (2026-10-22 ~ 2026-10-24)

### 1. 14 项通用正确性缺陷全链路闭环
在启动纯净基准前，团队对框架进行地毯式审计，彻底修复 14 项隐蔽缺陷：
1. 修复 SyncBN 在单卡/多流下的跨卡统计量越界污染；
2. 修复 BoxCoder 边界溢出引发的隐蔽 NaN 梯度（增加边界 clamp 守卫）；
3. 修复 P2-v10 跨尺度高频特征与 HybridEncoder 层级维度的严苛对齐；
4. 彻底移除 eval_idx 单应重映射几何漂移；
5. 闭环 test 阶段与 train 阶段的红外对齐流水线不对称性；
6. 修复 Co-ATSS 回归损失在 `co_aux_head.py` 与 `deim_criterion.py` 中的双重乘权 Bug；
7. 解决 micro-batch 梯度累加中计算图引用未解除导致的内存驻留；
8. 修复 depth 16-bit 归一化极值与反向倒转；
9. 升级现代算力混合精度引擎：启用 Blackwell BF16 AMP + TF32 + 异步 Pin-memory；
10. 修复分类 Head 正负样本权重不平衡截断；
11. 修复 EMA 权重衰减率热身步数越界；
12. 修复 Focal Loss 在零框纯背景图中的非有限梯度；
13. 修复夜化增强模块导入静默失败降级；
14. 修复全流程 CRLF 换行规范与多模态通道装配锁相。

### 2. 算力迁移与 Turbo 架构极限加速
- 由存在硬件位翻转故障的 ailab40 GPU1 迁移至 SeetaCloud RTX PRO 6000 Blackwell 单卡（96GB）；
- 实施 Blackwell Turbo 优化：原生 BF16 AMP（保持与 FP32 完全同构的 $10^{38}$ 动态指数范围，消除 FP16 溢出）+ TF32 + 8 进程持久异步预取，单步耗时由 2.25s 缩短至 0.76s（3.0× 加速），整周期训练压缩至 9.5 小时。
