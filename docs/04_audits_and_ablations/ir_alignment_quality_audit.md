## 二、上一轮“49 例异常劣化”根本归因与优化闭环

在初版流水线中，全量审计发现了 49 例 $\Delta CC < -0.005$ 的异常样本（如 `00000600`, `00000603`, `00000628` 等地面复杂街景）。经过深入底层数学与算子分析，成功定位了导致指标下沉的**三个根本原因**并完成了闭环重构：

### 1. 插值算子的高频低通滤波效应 (Bilinear Smoothing Degradation)
- **机理分析**：
  原代码在刚性仿射与稠密形变重采样时使用了 OpenCV 默认的双线性插值 (`cv2.INTER_LINEAR`)。连续经历仿射变形和网格重映射后，双线性插值产生了类似低通高斯滤波的模糊效应，削弱了红外图像细微边缘的高阶导数梯度幅值。
  当计算 Scharr 结构图时，细边梯度的幅值被平滑压低，导致数值上的皮尔逊相关系数表面上下降（但实际物理边缘其实重合更好）。
- **技术解法**：
  将全部重采样插值升级为**双三次样条插值 (`cv2.INTER_CUBIC`)**。双三次样条具备保锐（Sharpening）基函数特性，有效保全了亚像素级的高频几何跃变与梯度响应。测试表明，仅替换插值核就使 `00000600` 的基底相关度从 `0.378` 跃升至 `0.418`。

### 2. 阶段二局部吸附缺失全局防劣化熔断机制 (Missing Stage-2 Gate)
- **机理分析**：
  阶段一（全局仿射）和阶段三（引导滤波）均配置了严格的校验门限，但阶段二（热斑吸附）在初版中只要局部热斑通过了 `resp >= 0.40`，就会无条件施加网格重映射（`cv2.remap`）。
  在密集的建筑地面场景中（如窗格、栅栏、地砖纹理），相位相关法（Phase Correlate）在周期性微小结构上会产生局部相位折叠（Phase Wrap），导致相邻几像素内的几个热斑计算出互相矛盾的微小位移矢量（例如一个向左 +1.5px，一个向右 -0.7px），羽化重叠后导致局部纹理扭曲。
- **技术解法**：
  在阶段二引入**全局结构相关度安全熔断门限**：
  ```python
  if local_applied_count > 0:
      ig_snap = cv2.remap(ig_current, map_x, map_y, interpolation=cv2.INTER_CUBIC, ...)
      ie_snap = struct_map(ig_snap)
      cc_snap = float(np.corrcoef(ve.ravel().astype(float), ie_snap.ravel().astype(float))[0, 1])
      # 若局部吸附未破坏整体结构一致性则采纳，否则安全熔断回退
      if cc_snap >= cc_current - 0.001:
          ig_current = ig_snap
          ie_current = ie_snap
          cc_current = cc_snap
      else:
          local_applied_count = 0  # 触发熔断保护，回退全局对齐结果
  ```

### 3. 指标度量空间与实际产物空间的一致性拉齐
- **机理分析**：
  原代码在阶段一决策门限时计算的是 `warpAffine(ie)`（变形预计算的梯度图），而最终输出的是 `struct_map(warpAffine(ig))`（变形原图后再算梯度图）。两者存在微妙的算子顺序非对易性差异。
- **技术解法**：
  在阶段一中直接对候选红外原图 `ig_cand` 计算 `struct_map` 并度量相关度，确保决策门限与最终物理落盘图像处于严格相同的度量空间。
